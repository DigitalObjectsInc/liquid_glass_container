# liquid_glass_container example

Playground for [liquid_glass_container](../): a cursor-following glass pane
(the reference's spring physics), a hideable control panel driving every
`LiquidGlassSettings` field (fed to the scope, so the panes inherit),
switchable backgrounds and render modes, and an optional static pane with
content for glass-on-glass compositing.

Run it on any platform:

```sh
flutter run
```

Web measurement knobs: `?impl=full|fb`, `?bg=anim` (scrolling backdrop),
`?auto` (self-driving glass); profile builds print frame timings every 120
frames.

The package screenshots in `../doc/` are rendered frames, generated by
`test/screenshot_test.dart`:

```sh
GENERATE_SCREENSHOTS=1 flutter test test/screenshot_test.dart
```
